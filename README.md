# Breach Brief — site

Static landing page + legal pages for **Breach Brief** (educational cybersecurity content for
small-business owners), hosted on GitHub Pages.

- `index.html` — brand landing page
- `privacy.html` — Privacy Policy (required URL for the Meta / TikTok / LinkedIn developer apps)
- `terms.html` — Terms of Service

Live at: https://bnipper-creator.github.io/breach-brief/

No build step — plain HTML with inline CSS (Terminal brand palette). Edit and push to `main`;
GitHub Pages redeploys automatically.
